## 2. 대시보드

<그림>대시보드 화면

### 헤더 정보

<그림>헤더 Hot/Cold Wallet

- **Hot Wallet**: 운영 자금 잔액 (원화 환산)
- **Cold Wallet**: 보관 자금 잔액 (원화 환산)

### 실시간 알림 아이콘

<그림>헤더 알림 아이콘

| 아이콘 | 의미 | 클릭 시 이동 |
|--------|------|--------------|
| 👥 (초록색) | 새 회원 가입 | 사용자 및 지갑 관리 |
| ✅ (파란색) | 계좌 인증 요청 | 계좌 인증 관리 |
| 🛒 (보라색) | 코인 구매 요청 | 코인 구매 요청 관리 |

- 각 아이콘에 대기 건수 표시
- 새 알림 시 펄스 효과 및 사운드

### 종 알림 센터

<그림>종 알림 센터

- 종 아이콘 클릭 시 알림 패널 열림
- 모든 알림 시간순 표시
- 읽지 않은 알림 강조 표시
- 개별 읽음/삭제 가능
- "모두 읽음" / "모두 삭제" 기능

### 통계 카드

<그림>통계 카드

4가지 핵심 지표:
1. **전체 사용자 수**: 총 회원 수
2. **총 지갑 잔액**: 모든 지갑의 총 원화 환산액
3. **대기중인 입출금**: 승인 대기 건수
4. **완료된 거래 (오늘)**: 금일 처리 완료 건수

- 계좌 인증 상태

**검색 및 필터:**

- 인증 상태별 필터

### 사용자 상세

<그림>사용자 상세 모달

사용자 클릭 시:
- **기본 정보 탭:**
  - 사용자명, 이메일
  - 계좌인증 상태
  - 계정 상태 (활성/정지/차단)
  - 가입일, 마지막 로그인
  - **회원 등급 (변경 가능):** 드롭다운으로 즉시 변경
    - Basic ⚪
    - Standard ⭐
    - Premium 💎
    - VIP 👑
- **지갑 관리 탭:**
  - 모든 지갑 목록 및 잔액
  - 코인 추가 기능
- **관리 액션:**
  - 활성화/정지/차단 버튼

### 회원 등급 변경

<그림>등급 변경 드롭다운

**변경 방법:**
1. 사용자 목록에서 사용자 클릭
2. 기본 정보 탭에서 "회원 등급" 드롭다운 확인
3. 등급 선택 (Basic/Standard/Premium/VIP)
4. 즉시 DB 업데이트 + 사용자 모바일에 실시간 반영

**등급별 효과:**
- **VIP 👑**: 가스비 100% 무료 (가장 높은 등급)
- **Premium 💎**: 가스비 100% 무료
- **Standard ⭐**: 가스비 일부 지원
- **Basic ⚪**: 가스비 사용자 부담 (기본 등급)

**주의사항:**
- 등급 변경은 즉시 적용됩니다
- 사용자 모바일 앱에 실시간으로 반영됩니다
- 등급에 따라 가스비 정책이 자동 적용됩니다

### 사용자 정보 수정

<그림>정보 수정 모드

**기능:**
- 기본 정보 탭 우측 상단의 "정보 수정" 버튼 클릭

**수정 가능 항목:**
1. **사용자명:** 텍스트 입력
2. **이메일:** 텍스트 입력 (이메일 형식)

**수정 절차:**
1. "정보 수정" 버튼 클릭 → 편집 모드 활성화
2. 사용자명/이메일 수정
3. "저장" 버튼 클릭 → DB 업데이트
4. 또는 "취소" 버튼으로 변경 취소

**주의사항:**
- 이메일 변경 시 사용자에게 알림 전송 권장
- 중복 이메일 검증 필요

### 비밀번호 초기화

<그림>비밀번호 초기화 섹션

**간단한 프로세스:**

1. **임시 비밀번호 생성**
   - 기본 정보 탭 → "비밀번호 초기화" 섹션
   - "임시 비밀번호 생성" 버튼 클릭
   - 12자리 안전한 비밀번호 자동 생성

2. **비밀번호 복사 및 전달**
   - 복사 버튼으로 클립보드에 복사
   - 사용자에게 전달 (이메일/SMS/채팅)

3. **비밀번호 적용**
   - "적용" 버튼 클릭 → DB 반영

4. **사용자가 직접 변경**
   - 사용자는 모바일 앱 "설정 > 비밀번호 변경"에서 직접 변경 가능
   - 임시 비밀번호로 로그인 후 바로 변경 권장

### 인증 요청 목록

<그림>인증 요청 테이블

**표시 정보:**

- 은행명
- 계좌번호

- 상태 (대기중/완료/거절됨)

### 1원 인증 처리

<그림>인증 처리 화면

#### 승인 절차
1. 대기중인 요청 확인
2. 사용자 계좌로 **1원 입금**
   - 입금자명: `예금주명XXXX` (XXXX는 4자리 랜덤 숫자)
   - 예: 홍길동 → 입금자명: "홍길1234"
3. GMS에서 상태가 자동 업데이트됨
4. 사용자가 앱에서 4자리 코드 입력 대기
5. 코드 일치 시 자동 인증 완료

#### 거절
1. "거절" 버튼 클릭
2. 거절 사유 입력 (예: "예금주명 불일치")
3. 확인
4. 사용자에게 사유 전달

### 구매 요청 처리

<그림>구매 처리 화면

#### 승인 절차
1. 대기중인 요청 확인
2. **관리자 계좌 입금 확인**:
   - 인터넷뱅킹에서 입금 내역 확인

   - 사용자 지갑에 코인 지급

1. "거절" 버튼 클릭
2. 거절 사유 입력 (예: "입금 미확인", "입금자명 불일치")
3. 확인
4. 사용자에게 거절 사유 전달

- 사용자명, 입금자명으로 검색

## 9. 가스비 정책 관리

<그림>가스비 정책 화면

### Biconomy 가스 스폰서십 설정

<그림>정책 설정

**회원 등급별 정책:**

| 등급 | 기본 정책 | 설정 가능 항목 |
|------|----------|---------------|
| 🟡 VIP | 100% 운영자 부담 | 스폰서 모드, 설명 |
| 🟣 Premium | 100% 운영자 부담 | 스폰서 모드, 설명 |
| 🔵 Standard | 부분 지원 | 스폰서 모드, 최대 사용자 부담액, 가스 토큰 |
| ⚪ Basic | 100% 사용자 부담 | 스폰서 모드, 가스 토큰 |

**스폰서 모드:**
- **100% 운영자 부담**: 사용자는 가스비를 전혀 지불하지 않음 (VIP, Premium 권장)
- **부분 지원**: 사용자는 일정 금액까지만 부담하고 초과분은 운영자가 부담
  - 예: 최대 사용자 부담액 1 USDC → 가스비가 2 USDC면 사용자는 1 USDC만 부담
- **100% 사용자 부담**: 사용자가 USDC로 가스비 전액 지불

**가스비 토큰:**
- Biconomy는 USDC만 가스비 토큰으로 지원
- 사용자 부담 시 사용자의 USDC 잔액에서 차감

### 정책 설정 방법

1. 각 등급 카드에서 스폰서 모드 선택
2. 부분 지원 시 최대 사용자 부담액 입력
3. 사용자 부담 시 가스 토큰 확인 (USDC 고정)
4. 설명 입력 (사용자에게 표시됨)
5. 활성화 체크박스 ON
6. "저장하기" 버튼 클릭

### 가스비 모니터

<그림>가스비 모니터

**현재 지표:**
- **활성 정책**: 현재 활성화된 정책 개수 (최대 4개)
- **100% 스폰서**: 완전 무료 정책 개수 (VIP/Premium)
- **부분 스폰서**: 부분 지원 정책 개수 (Standard)

**Backend 통합:**
- ✅ Biconomy API 호출이 Backend(Supabase Edge Function)에서 안전하게 처리
- ✅ CORS 에러 해결 및 보안 강화
- ✅ API Key 노출 방지
- ✅ 사용자는 Frontend만 사용하여 안전한 거래 가능

**향후 개발 예정:**
- 현재 Gas Price (네트워크별)
- 오늘 스폰서된 가스비 총액
- 트랜잭션 건수 (성공/실패)
- 평균 비용 및 절감액

### 주의사항

- ✅ **정책 변경은 즉시 적용됩니다**
  - 저장 즉시 DB 업데이트
  - 사용자 모바일에 실시간 반영 (새로고침 불필요)
  - Backend API를 통해 안전하게 처리
- ✅ **VIP/Premium 회원의 가스비는 운영자 부담이 권장됩니다**
  - 최고 등급 회원에 대한 우대 정책
  - 사용자 만족도 및 충성도 향상
- ✅ **부분 지원 시 최대 부담액을 적절히 설정하세요**
  - 사용자 부담이 과도하지 않도록 주의
  - Standard 등급 권장: 1-2 USDC
- ✅ **가스비 토큰은 USDC만 지원됩니다**
  - Biconomy API 정책
  - 사용자가 USDC 잔액 부족 시 출금 불가

## 11. 고객센터 (실시간 문의)

<그림>고객센터 화면

### 개요
사용자의 실시간 문의를 관리하고 답변하는 1:1 채팅 시스템입니다.

### 화면 구성

<그림>2단 레이아웃

**왼쪽 패널 - 사용자 목록:**
- 문의한 모든 사용자 목록 표시
- 최근 메시지 시간순 정렬
- 각 사용자별 정보:
  - 사용자명
  - 이메일
  - 마지막 메시지 미리보기
  - 시간 (월/일, 시:분)
  - 읽지 않은 메시지 개수 (파란색 배지)

**검색 기능:**
- 사용자명 또는 이메일로 검색
- 실시간 필터링

**오른쪽 패널 - 채팅 영역:**
- 선택된 사용자와의 대화 표시
- 헤더: 사용자명 + 이메일
- 메시지 영역:
  - 사용자 메시지: 왼쪽, 회색 배경
  - 관리자 메시지: 오른쪽, 파란색 그라데이션
  - 각 메시지별 시간 표시
- 입력 영역:
  - 텍스트 입력창
  - 전송 버튼 (Send 아이콘)

### 실시간 기능

**자동 업데이트:**
- ✅ 새 문의 도착 시 즉시 토스트 알림
- ✅ 사용자 목록 자동 업데이트
- ✅ 채팅 중 메시지 실시간 동기화
- ✅ 읽지 않은 메시지 자동 읽음 처리
- ✅ 자동 스크롤 (최신 메시지로)

**알림:**
- 새 문의: "사용자ID님으로부터 새 문의가 도착했습니다"
- 읽지 않은 배지: 파란색 원형 배지에 숫자 표시

### 사용 방법

#### 1단계: 사용자 선택
1. 왼쪽 목록에서 문의한 사용자 클릭
2. 읽지 않은 메시지가 있으면 배지 표시
3. 선택 시 배경색 변경 (회색 강조)

#### 2단계: 대화 내용 확인
1. 오른쪽에 전체 대화 내역 표시
2. 사용자가 보낸 문의 내용 확인
3. 이전 대화 기록 스크롤하여 확인 가능

#### 3단계: 답변 작성
1. 하단 입력창에 답변 작성
2. Enter 키 또는 "전송" 버튼 클릭
3. 메시지 즉시 전송
4. 사용자 모바일에 실시간 알림

#### 4단계: 읽음 처리
- 사용자 메시지는 자동으로 읽음 처리
- 읽지 않은 배지 자동 감소

### 활용 팁

**신속한 대응:**
- 읽지 않은 메시지가 많은 사용자 우선 처리
- 검색 기능으로 특정 사용자 빠르게 찾기

**효율적인 관리:**
- 자주 하는 질문에 대한 템플릿 준비 권장
- 복잡한 문제는 상세히 안내

**모니터링:**
- 주기적으로 고객센터 메뉴 확인
- 대기 중인 문의 빠르게 처리
