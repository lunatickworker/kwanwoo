## 2. 홈 화면

<그림>홈 화면

### 총 자산 카드
- 전체 코인의 원화(KRW) 환산 총액 표시
- 눈 아이콘으로 잔액 숨김/표시 토글
- 일일 변동률 표시 (%)

### 빠른 액션 버튼
- **입금하기**: 코인 입금 화면으로 이동
- **출금하기**: 코인 출금 화면으로 이동
- **스왑**: 코인 환전 화면으로 이동

### 코인 구매 요청 버튼
- 계좌 인증 완료 시: 구매 요청 화면으로 이동
- 미인증 시: 설정 화면으로 이동 (인증 안내)

### 내 코인 목록
- 보유 중인 코인 목록 (최대 5개 표시)
- 각 코인별 잔액 및 원화 환산액
- 코인 클릭 시 지갑 상세 화면으로 이동

### 최근 거래 내역
- 최근 3건의 입출금 내역 표시
- 전체보기 버튼으로 전체 내역 확인

<그림>지갑 목록 화면

### 지갑 목록

- 각 지갑별 잔액 및 원화 환산액
- 코인 클릭 시 상세 화면으로 이동

- 해당 코인의 거래 내역 목록

## 4. 입금 (Deposit)

<그림>입금 화면

### 입금 절차
1. **코인 선택**: 드롭다운에서 입금할 코인 선택
2. **입금 주소 확인**:
   - QR 코드 표시
   - 텍스트 주소 표시 및 복사 버튼
3. **외부에서 전송**: 복사한 주소로 코인 전송
4. **입금 대기**: 블록체인 확인 중 (자동 반영)

### 최근 입금 내역
- 최근 5건의 입금 내역 표시
- 상태: 대기중/확인중/완료
- 실시간 업데이트 (새 입금 시 알림)

---

## 5. 출금 (Withdrawal)

<그림>출금 화면

### 출금 절차
1. **코인 선택**: 출금할 코인 선택
2. **정보 입력**:
   - 받는 주소 입력
   - 출금 수량 입력 (MAX 버튼 사용 가능)
3. **가스비 정책 확인**:
   - 내 회원 등급에 따른 가스비 부담 비율 표시
   - VIP/Premium: 가스비 무료 (100% 운영자 부담)
   - Standard: 일부 부담 (초과분은 운영자 부담)
   - Basic: 전액 사용자 부담 (USDC로 지불)
4. **출금 요청**: "출금하기" 버튼 클릭
5. **자동 처리**: 즉시 블록체인 전송 시작
6. **완료**: 블록체인 확인 후 완료

### 가스비 정책
회원 등급에 따라 가스비 부담이 다릅니다:

| 등급 | 가스비 부담 | 설명 |
|------|------------|------|
| 🟡 VIP | 0% (무료) | 모든 가스비를 운영자가 부담 |
| 🟣 Premium | 0% (무료) | 모든 가스비를 운영자가 부담 |
| 🔵 Standard | 일부 부담 | 일정 금액까지만 부담 (예: 최대 1 USDC) |
| ⚪ Basic | 100% 부담 | USDC로 가스비 지불 필요 |

### 최근 출금 내역
- 최근 5건의 출금 내역 표시
- 상태: 처리중/완료/실패
- 스마트 거래 사용 여부 표시

---

## 6. 스왑 (Swap)

<그림>스왑 화면

### 스왑 절차
1. **From 코인**: 보낼 코인 선택 및 수량 입력
2. **To 코인**: 받을 코인 선택
3. **예상 수령액**: 자동 계산되어 표시
4. **스왑 실행**: "스왑하기" 버튼 클릭
5. **완료**: 즉시 잔액 반영

### 편의 기능
- MAX 버튼: 전액 스왑
- 코인 교체 버튼: From ↔ To 빠른 전환
- 실시간 환율 표시

---

## 7. 코인 구매 요청

<그림>코인 구매 요청 화면

> ⚠️ **계좌 인증 필수**: 미인증 시 사용 불가

### 구매 절차
1. **코인 선택**: KRWQ 또는 USDT 선택
2. **금액 입력**: 원화(KRW) 금액 입력
   - 계산기 패드 사용
   - 빠른 금액 버튼 (10만원, 50만원, 100만원, 500만원)
3. **입금자명 입력**: 실제 송금할 이름
4. **구매 요청**: "구매 요청하기" 버튼 클릭
5. **안내된 계좌로 입금**:
   - 은행, 계좌번호, 예금주, 금액 확인
   - **입금자명 정확히 일치 필수**
6. **관리자 확인 대기**
7. **코인 지급**: 승인 후 자동 입금

### 최근 요청 내역
- 대기중/승인됨/완료/거절됨 상태 표시
- 각 요청별 상세 정보 확인

## 8. 거래 내역 (Transactions)

<그림>거래 내역 화면

### 전체 내역 조회
- 모든 입금/출금 거래 내역 표시

- 날짜 및 시간

## 9. 계좌 인증

<그림>계좌 인증 화면

> 🔒 **필수 기능**: 입금/출금/스왑/구매 모두 인증 후 사용 가능

### 인증 절차

#### 1단계: 계좌 정보 입력
- 은행명 선택 (드롭다운)
- 계좌번호 입력
- 예금주 입력
- "인증 요청" 버튼 클릭

#### 2단계: 1원 입금 대기
- 관리자가 계좌로 1원 입금
- 입금자명에 **4자리 인증 코드** 포함
- 예: "홍길1234" → 인증 코드는 **1234**

#### 3단계: 인증 코드 입력
- 통장/앱에서 입금자명 확인
- 뒤 4자리 숫자 입력
- "확인" 버튼 클릭

#### 4단계: 인증 완료
- ✅ 인증 완료 시 모든 기능 사용 가능
- ❌ 거절 시 사유 확인 후 재시도

### 인증 상태
- **대기중**: 1원 입금 대기
- **코드 전송됨**: 코드 입력 필요
- **확인됨**: 인증 완료 ✅
- **거절됨**: 재시도 필요

## 10. 설정 (Settings)

<그림>설정 화면

### 프로필 정보
- 사용자명
- 이메일
- 계좌 인증 상태 배지 (초록색 "인증완료")
- 회원 등급 배지 (VIP/Premium/Standard/Basic)

### 회원 혜택 카드
- 현재 회원 등급 표시 (아이콘 + 텍스트)
- 등급별 가스비 혜택 한 줄 요약
  - VIP 👑: "가스비 100% 무료 🎉"
  - Premium 💎: "가스비 100% 무료 🎉"
  - Standard ⭐: "최대 X USDC까지만 부담 ✨"
  - Basic ⚪: "출금 가스비는 본인 부담"
- 출금 가스비 상태 표시 (색상 강조)
- **실시간 업데이트**: 관리자가 등급/정책 변경 시 즉시 반영 (새로고침 불필요)

### 1원 계좌인증
- 현재 인증 상태 확인
- 인증 화면으로 이동 버튼
- 미인증 시: "출금을 위해 인증이 필요합니다"
- 인증 완료 시: "인증 완료"

### 앱 설정
**알림 설정:**
- 간편 토글 스위치 (ON/OFF)
- ON (파란색): 거래 알림, 시스템 알림, 고객센터 답변 알림 수신
- OFF (회색): 모든 알림 비활성화
- 설정 즉시 저장

### 고객 지원
**실시간 문의:**
- 클릭 시 전체 화면 채팅 모달 오픈
- 관리자와 1:1 실시간 대화
- 기능:
  - 메시지 전송 (텍스트 입력 + 전송 버튼)
  - Enter 키로 빠른 전송
  - 실시간 메시지 수신 (관리자 답변 즉시 표시)
  - 메시지 전송 시간 표시
  - 자동 스크롤 (최신 메시지로)
  - 읽음 처리 자동화
- 디자인:
  - 내 메시지: 오른쪽, 파란색 그라데이션
  - 관리자 메시지: 왼쪽, 회색 배경
  - 시간 표시 (오전/오후 시:분)

### 버전 정보
- 현재 앱 버전 표시 (1.0.0)

### 로그아웃
- "로그아웃" 버튼 클릭
- 로그인 화면으로 이동

## ⚠️ 주의사항

### 입금 시
- 정확한 주소로 전송
- 네트워크 확인 필수
- 소액 테스트 권장

### 출금 시
- 주소 오타 주의 (복구 불가)
- 출금은 즉시 처리되며 되돌릴 수 없습니다
- 네트워크 수수료 별도 차감

### 코인 구매 시
- **입금자명 정확히 일치** 필수
- 정확한 금액 입금
- 영업시간 내 빠른 처리

### 계좌 인증
- 실명 계좌만 가능
- 정확한 정보 입력
- 인증 코드 4자리 정확히 입력
