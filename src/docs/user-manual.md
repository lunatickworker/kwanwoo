## 1. 시작하기

### 1.1 첫 접속 및 로그인

<그림>모바일 로그인 화면

1. **앱 접속**: 브라우저에서 제공된 URL로 접속
2. **로그인**:
   - 아이디 입력
   - 비밀번호 입력
   - "로그인" 버튼 클릭

> ⚠️ **주의**: 관리자 계정으로는 모바일 앱을 사용할 수 없습니다.

### 1.2 계좌 인증 (필수)

처음 가입 후 모든 기능을 사용하려면 **1원 인증**을 완료해야 합니다.

<그림>계좌 인증 안내 배너

**인증이 완료되지 않으면:**
- ❌ 입금 불가
- ❌ 출금 불가
- ❌ 스왑 불가
- ❌ 코인 구매 불가
- ✅ 잔액 조회만 가능

## 2. 홈 화면

<그림>홈 화면 전체

홈 화면은 앱을 열면 가장 먼저 보이는 메인 화면입니다.

### 2.1 화면 구성

#### 상단 바
- **사용자 정보**: 현재 로그인된 계정 표시
- **알림 아이콘**: 새로운 알림 확인

#### 총 자산
<그림>총 자산 카드

- **총 보유 자산**: 모든 코인의 원화(KRW) 환산 총액
- **실시간 업데이트**: 코인 가격 변동에 따라 자동 갱신

#### 빠른 액션 버튼
<그림>빠른 액션 버튼

| 버튼 | 기능 |
|------|------|
| **입금** | 코인 입금하기 |
| **출금** | 코인 출금하기 |
| **스왑** | 코인 환전하기 |
| **구매** | 코인 구매 요청 |

#### 내 지갑 목록
<그림>지갑 목록 카드

- **지원 코인**: BTC, ETH, USDT, USDC, BNB, KRWQ
- **각 코인별**:
  - 코인 아이콘 및 이름
  - 보유 수량
  - 원화 환산액
  - 상태 (활성/비활성)

#### 최근 거래 내역
<그림>최근 거래 내역

- **최근 20건** 표시
- **거래 정보**:
  - 거래 타입 (입금/출금)
  - 코인 종류
  - 수량
  - 상태 (대기중/완료/실패)
  - 날짜 및 시간

### 2.2 하단 내비게이션

<그림>하단 내비게이션 바

| 아이콘 | 메뉴 | 설명 |
|--------|------|------|
| 🏠 | **홈** | 메인 대시보드 |
| 💼 | **지갑** | 지갑 상세 관리 |
| 🔄 | **스왑** | 코인 환전 |
| 📜 | **거래내역** | 전체 거래 기록 |
| ⚙️ | **설정** | 계정 설정 |

## 3. 지갑 관리

<그림>지갑 화면

### 3.1 지갑 목록 보기

하단 내비게이션에서 **💼 지갑** 탭을 선택합니다.

**표시 정보:**
- 각 코인별 보유량
- 원화 환산액
- 지갑 주소 (일부)
- 활성화 상태

### 3.2 지갑 상세 정보

<그림>지갑 상세 화면

특정 코인을 탭하면 상세 정보를 확인할 수 있습니다.

**상세 정보:**
- 💰 **잔액**: 정확한 코인 수량
- 📍 **지갑 주소**: 전체 주소 (복사 가능)
- 💵 **원화 환산**: 현재 환율 기준 가치
- 📊 **상태**: 지갑 활성화 여부

**빠른 액션:**
- **입금**: 이 코인 입금하기
- **출금**: 이 코인 출금하기
- **스왑**: 다른 코인으로 환전

### 3.3 지갑 주소 복사

<그림>주소 복사 버튼

1. 지갑 주소 오른쪽의 **복사 아이콘** 클릭
2. "주소가 복사되었습니다" 메시지 확인
3. 다른 앱에 붙여넣기

> ⚠️ **주의**: 입금 시 반드시 정확한 주소를 사용하세요!

## 4. 입금하기

<그림>입금 화면

### 4.1 입금 절차

#### Step 1: 입금 화면 열기
- 홈 화면에서 **"입금"** 버튼 클릭
- 또는 지갑 상세에서 **"입금"** 선택

#### Step 2: 코인 선택
<그림>코인 선택 드롭다운

- 드롭다운에서 입금할 코인 선택
- BTC, ETH, USDT, USDC, BNB, KRWQ 지원

#### Step 3: 입금 주소 확인
<그림>입금 주소 QR코드

**입금 주소 카드:**
- 📱 **QR 코드**: 스캔용
- 📋 **텍스트 주소**: 복사 가능
- ⚠️ **네트워크 정보**: 반드시 확인!

**주소 복사 방법:**
1. "주소 복사" 버튼 클릭
2. 확인 메시지 표시
3. 외부 거래소/지갑에 붙여넣기

#### Step 4: 외부에서 전송
1. 외부 거래소 또는 다른 지갑에서
2. 복사한 주소로 코인 전송
3. 네트워크 확인 (예: ERC-20, TRC-20 등)

#### Step 5: 입금 완료 대기
<그림>입금 대기 상태

- **블록체인 확인 대기**: 약 10-30분 소요
- **상태 확인**: 거래내역에서 실시간 확인
- **알림**: 입금 완료 시 자동 알림

### 4.2 입금 시 주의사항

> ⚠️ **반드시 확인하세요!**

| 항목 | 설명 |
|------|------|
| **네트워크** | 코인과 네트워크가 일치해야 합니다 |
| **최소 금액** | 너무 작은 금액은 수수료로 손실 |
| **주소 확인** | 복사 시 오타 주의 |
| **메모/태그** | 일부 코인은 메모 필수 (XRP, XLM 등) |

**입금이 안 될 때:**
1. 네트워크 선택 확인
2. 트랜잭션 해시(TxHash) 확인
3. 블록체인 탐색기에서 확인 횟수 체크
4. 고객센터 문의 (TxHash 제공)

## 5. 출금하기

<그림>출금 화면

### 5.1 출금 절차

#### Step 1: 출금 화면 열기
- 홈 화면에서 **"출금"** 버튼 클릭
- 또는 지갑 상세에서 **"출금"** 선택

#### Step 2: 정보 입력
<그림>출금 정보 입력 폼

**입력 항목:**
1. **코인 선택**: 출금할 코인 타입
2. **출금 주소**: 받을 지갑 주소 입력
3. **수량**: 출금할 코인 수량
4. **네트워크**: 블록체인 네트워크 선택 (중요!)

**편의 기능:**
- 💰 **MAX 버튼**: 전액 출금
- 📊 **잔액 표시**: 현재 보유량 확인
- 💵 **원화 환산**: 실시간 가치 표시

#### Step 3: 출금 정보 확인
<그림>출금 확인 팝업

**확인 사항:**
- ✅ 출금 코인 및 수량
- ✅ 받는 주소
- ✅ 네트워크 수수료
- ✅ 실제 받을 금액

> ⚠️ **주의**: 출금은 취소할 수 없습니다!

#### Step 4: 출금 요청
1. "출금하기" 버튼 클릭
2. 확인 메시지 읽기
3. "확인" 버튼으로 최종 승인

#### Step 5: 관리자 승인 대기
<그림>출금 대기 상태

**처리 절차:**
1. **대기중**: 관리자 검토 대기
2. **승인됨**: 블록체인 전송 중
3. **완료**: 출금 완료
4. **거절**: 사유와 함께 거절 (잔액 복구)

**소요 시간:**
- 관리자 승인: 영업일 기준 1-24시간
- 블록체인 전송: 10-30분 (네트워크별 상이)

### 5.2 출금 시 주의사항

> ⚠️ **출금 전 필수 확인!**

| 항목 | 주의사항 |
|------|----------|
| **주소** | 한 글자라도 틀리면 코인 분실! |
| **네트워크** | 반드시 받는 쪽과 동일해야 함 |
| **수수료** | 네트워크 수수료는 별도 차감 |
| **최소 금액** | 수수료보다 큰 금액만 가능 |
| **메모/태그** | 필요한 코인은 반드시 입력 |

**출금이 거절되는 경우:**
- ❌ 계좌 인증 미완료
- ❌ 잔액 부족
- ❌ 잘못된 주소 형식
- ❌ 의심스러운 활동 감지
- ❌ 최소 출금액 미만

## 6. 스왑 (환전)

<그림>스왑 화면

코인 간 환전 기능입니다. 예: BTC → ETH

### 6.1 스왑 절차

#### Step 1: 스왑 화면 열기
- 홈 화면에서 **"스왑"** 버튼 클릭
- 또는 하단 내비게이션에서 **🔄 스왑** 선택

#### Step 2: 환전 정보 입력
<그림>스왑 입력 폼

**입력 항목:**
1. **보내는 코인**: 현재 보유한 코인 선택
2. **보낼 수량**: 환전할 수량 입력
3. **받는 코인**: 환전 받을 코인 선택

**자동 계산:**
- 💱 **환율**: 실시간 환율 자동 적용
- 💰 **예상 수령액**: 자동 계산 표시
- 💸 **수수료**: 포함된 총 비용

**편의 기능:**
- **MAX**: 전액 환전
- **25% / 50% / 75%**: 비율 선택
- **코인 교체**: ⇅ 버튼으로 빠른 교체

#### Step 3: 환율 확인
<그림>환율 정보 카드

**표시 정보:**
- 📊 **현재 환율**: 1 BTC = ? ETH
- ⏰ **갱신 시간**: 마지막 업데이트 시각
- 💵 **원화 기준**: KRW 환산액
- 📉 **슬리피지**: 예상 가격 변동폭

#### Step 4: 스왑 실행
<그림>스왑 확인 다이얼로그

**확인 화면:**
```
보내는 코인: 0.1 BTC
받는 코인: 2.5 ETH
환율: 1 BTC = 25 ETH
수수료: 0.001 BTC
총 비용: 0.101 BTC
```

1. 정보 최종 확인
2. "스왑하기" 버튼 클릭
3. 완료 메시지 확인

#### Step 5: 완료 확인
<그림>스왑 완료 화면

- ✅ **즉시 반영**: 잔액 실시간 업데이트
- 📜 **거래 기록**: 거래내역에 자동 저장
- 🔔 **알림**: 스왑 완료 알림

### 6.2 스왑 수수료

**수수료 구조:**
- **기본 수수료**: 거래액의 0.1% - 0.5%
- **네트워크 수수료**: 블록체인 가스비
- **슬리피지**: 시장 변동 보호

**절약 팁:**
- 📉 네트워크 혼잡도 낮을 때
- 💰 큰 금액 한 번에 처리
- ⏰ 피크 시간대 피하기

### 6.3 스왑 시 주의사항

> 💡 **스마트하게 환전하기**

| 팁 | 설명 |
|-----|------|
| **환율 비교** | 다른 거래소와 비교 추천 |
| **수수료 확인** | 숨겨진 수수료 없는지 체크 |
| **시장 변동** | 급등/급락 시기는 피하기 |
| **분할 거래** | 큰 금액은 나눠서 처리 |

## 7. 코인 구매 요청

<그림>코인 구매 화면

계좌 이체로 코인을 구매하는 기능입니다.

### 7.1 구매 절차

#### Step 1: 구매 화면 열기
- 홈 화면에서 **"구매"** 버튼 클릭

#### Step 2: 구매 정보 입력
<그림>구매 요청 폼

**입력 항목:**
1. **구매할 코인**: 원하는 코인 선택
2. **금액**: 구매할 원화(KRW) 금액
3. **입금자명**: 실제 송금할 이름 입력

**자동 계산:**
- 💰 **예상 수량**: 현재 시세로 계산
- 💵 **환율**: 실시간 코인 가격
- 📊 **총 비용**: 수수료 포함 금액

**예시:**
```
구매 코인: BTC
금액: 1,000,000원
입금자명: 홍길동
→ 예상 수량: 0.015 BTC
```

#### Step 3: 입금 정보 확인
<그림>입금 안내 화면

**입금 계좌 정보:**
```
은행: 국민은행
계좌번호: 123-456-789012
예금주: (주)크립토
입금액: 1,000,000원
입금자명: 홍길동 (필수!)
```

> ⚠️ **중요**: 입금자명을 정확히 입력해야 처리됩니다!

#### Step 4: 계좌 이체
1. 인터넷뱅킹 또는 앱으로 이동
2. 안내된 계좌로 정확한 금액 송금
3. **입금자명 반드시 확인**

#### Step 5: 관리자 확인 대기
<그림>구매 요청 대기 상태

**처리 단계:**
1. **대기중**: 입금 확인 대기
2. **승인됨**: 입금 확인 완료
3. **완료**: 코인 지급 완료
4. **거절**: 사유와 함께 거절 (환불 처리)

**소요 시간:**
- 입금 확인: 영업일 기준 1-6시간
- 코인 지급: 확인 즉시

### 7.2 구매 시 주의사항

> ⚠️ **반드시 확인하세요!**

| 항목 | 주의사항 |
|------|----------|
| **입금자명** | 요청 시 입력한 이름과 정확히 일치 |
| **금액** | 정확한 금액 입금 (원 단위까지) |
| **영업시간** | 평일 09:00-18:00 빠른 처리 |
| **최소 금액** | 최소 구매 금액 확인 필요 |

**구매가 거절되는 경우:**
- ❌ 입금자명 불일치
- ❌ 금액 불일치
- ❌ 계좌 인증 미완료
- ❌ 의심스러운 입금

**환불 정책:**

## 9. 계좌 인증

<그림>계좌 인증 화면

모든 기능을 사용하려면 **1원 인증**이 필수입니다.

### 9.1 인증이 필요한 이유

**보안 및 본인 확인:**
- 🔒 자금 세탁 방지 (AML)
- 👤 본인 확인 (KYC)
- 🛡️ 계정 보안 강화
- ⚖️ 법규 준수

### 9.2 인증 절차

#### Step 1: 계좌 인증 화면 열기
- 홈 화면 상단의 **"계좌 인증 필요"** 배너 클릭
- 또는 설정 > **"계좌 인증"** 메뉴

#### Step 2: 계좌 정보 입력
<그림>계좌 정보 입력 폼

**입력 항목:**
1. **은행명**: 드롭다운에서 선택
2. **계좌번호**: 숫자만 입력 (하이픈 없이)
3. **예금주**: 실명 입력

**예시:**
```
은행: 국민은행
계좌번호: 12345678901234
예금주: 홍길동
```

#### Step 3: 인증 요청 제출
1. 정보 확인
2. "인증 요청" 버튼 클릭
3. 제출 완료 메시지 확인

#### Step 4: 1원 입금 대기
<그림>1원 입금 대기 화면

- **소요 시간**: 영업일 기준 1-6시간
- **입금 금액**: 1원
- **입금자**: (주)크립토 또는 관리자명

#### Step 5: 입금자명 확인
<그림>입금 내역 확인

1. 인터넷뱅킹 또는 뱅킹 앱 열기
2. 입금 내역 확인
3. 입금자명 4자리 숫자 확인 (예: "홍길1234")

#### Step 6: 인증 코드 입력
<그림>인증 코드 입력

1. 계좌 인증 화면 재방문
2. 입금자명의 **뒤 4자리 숫자** 입력
3. "확인" 버튼 클릭

**예시:**
- 입금자명: 홍길1234
- 입력할 코드: **1234**

#### Step 7: 인증 완료
<그림>인증 완료 화면

- ✅ **인증 완료**: 모든 기능 사용 가능
- 🎉 **환영 메시지**: 인증 완료 알림
- 🔓 **제한 해제**: 입출금 가능

### 9.3 인증 상태 확인

<그림>인증 상태 카드

**상태별 의미:**
- 🟡 **대기중**: 1원 입금 대기
- 🟢 **완료**: 인증 성공
- 🔴 **거절**: 정보 불일치 (재시도 필요)

### 9.4 인증 실패 시

**실패 사유:**
- ❌ 계좌 정보 오류
- ❌ 예금주명 불일치
- ❌ 계좌 사용 불가 (폐쇄, 정지 등)

**해결 방법:**
1. 계좌 정보 재확인
2. 정확한 정보로 다시 요청
3. 고객센터 문의 (계좌 사본 제출)

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 입금이 반영되지 않아요
**A.** 블록체인 확인에는 시간이 걸립니다.
- BTC: 10-60분 (6확인)
- ETH: 5-15분 (12확인)
- USDT: 네트워크에 따라 상이

트랜잭션 해시로 블록체인 탐색기에서 확인하세요.

### Q2. 출금이 거절되었어요
**A.** 거절 사유를 확인하세요.
- 계좌 인증 미완료
- 잘못된 주소 형식
- 의심스러운 활동 감지

거래 내역에서 상세 사유를 확인할 수 있습니다.

### Q3. 수수료는 얼마인가요?
**A.** 거래 타입별로 다릅니다.
- 입금: 무료 (네트워크 수수료는 발신자 부담)
- 출금: 네트워크 수수료만
- 스왑: 0.1% - 0.5%
- 구매: 시세에 포함

### Q4. 계좌 인증은 얼마나 걸리나요?
**A.** 영업일 기준 1-6시간 소요됩니다.
주말 및 공휴일에는 다음 영업일에 처리됩니다.

### Q5. 코인 구매 취소가 가능한가요?
**A.** 입금 전에는 가능합니다.
입금 후에는 관리자 승인 전까지만 취소 가능합니다.

### Q6. 비밀번호를 잊어버렸어요
**A.** 비밀번호 찾기 기능을 사용하세요.
등록된 이메일로 재설정 링크가 발송됩니다.

### Q7. 여러 기기에서 사용 가능한가요?
**A.** 네, 가능합니다.
동일 계정으로 여러 기기에서 로그인 가능하며,
보안을 위해 새 기기 로그인 시 알림이 발송됩니다.

### Q8. 최소 거래 금액이 있나요?
**A.** 네, 코인별로 다릅니다.
- BTC: 0.0001 BTC
- ETH: 0.001 ETH
- USDT: 10 USDT
- KRWQ: 1,000 KRWQ

네트워크 수수료보다 큰 금액이어야 합니다.
