## 2. 대시보드

<그림>대시보드 전체 화면

관리자 페이지의 첫 화면으로, 시스템 전반의 상태를 실시간으로 확인할 수 있습니다.

### 2.1 헤더 정보

<그림>헤더 지갑 잔액

**Hot Wallet & Cold Wallet 잔액:**
- 🔥 **Hot Wallet**: 운영 자금 (즉시 출금 가능)
- 🧊 **Cold Wallet**: 보관 자금 (보안 우선)
- 💵 **원화 환산**: 실시간 총액 표시

**알림 아이콘:**
<그림>헤더 알림 아이콘

- 🟢 **회원가입** (UserPlus 아이콘): 새 회원 가입
- 🔵 **1원 인증** (FileCheck 아이콘): 계좌 인증 요청
- 🟣 **구매 요청** (ShoppingCart 아이콘): 코인 구매 요청

각 아이콘에 대기 건수 배지가 표시됩니다.

### 2.2 통계 카드

<그림>통계 카드 4개

**4가지 핵심 지표:**

#### 1️⃣ 전체 사용자 수
```
👥 전체 사용자
125명
+12 (지난 주)
```

#### 2️⃣ 총 지갑 잔액
```
💰 총 지갑 잔액
₩152,450,000
+15.2% (지난 주)
```

#### 3️⃣ 대기중인 입출금
```
⏳ 대기중인 거래
23건
입금: 15건 / 출금: 8건
```

#### 4️⃣ 완료된 거래 (오늘)
```
✅ 완료된 거래
87건
성공률: 98.5%
```

### 2.3 실시간 차트

<그림>거래량 추이 차트

**일별 거래량 차트:**
- 📊 지난 7일 거래 추이
- 💰 입금/출금/스왑 분리 표시
- 📈 트렌드 분석

**코인별 비중:**
<그림>코인 분포 원형 차트

- 🥧 파이 차트로 시각화
- 각 코인의 보유 비율 표시
- 클릭 시 상세 정보

### 2.4 최근 활동

<그림>최근 활동 테이블

**실시간 활동 로그:**
- ⏰ 최근 50건 표시
- 🔄 자동 갱신 (30초마다)
- 📝 상세 정보:
  - 사용자명
  - 활동 타입 (입금/출금/스왑/가입)
  - 금액 및 코인
  - 상태
  - 시각

**필터 옵션:**
- 활동 타입별
- 사용자별
- 시간대별

## 3. 사용자 및 지갑 관리

<그림>사용자 관리 화면

### 3.1 사용자 목록

<그림>사용자 목록 테이블

**표시 정보:**
- 👤 **사용자명**: 로그인 ID
- 📧 **이메일**: 연락처
- 🔐 **역할**: user / admin
- ✅ **계좌 인증 상태**: 완료 / 대기 / 미인증
- 📅 **가입일**: 계정 생성일
- 🎯 **액션**: 관리 버튼

**검색 및 필터:**
<그림>검색 바 및 필터

- 🔍 **검색**: 사용자명, 이메일로 검색
- 🎚️ **필터**:
  - 역할별 (전체/사용자/관리자)
  - 인증 상태별
  - 가입일 기준

**정렬 옵션:**
- 이름순 (A-Z, Z-A)
- 가입일순 (최신/오래된 순)
- 잔액순 (높은/낮은 순)

### 3.2 사용자 상세 정보

<그림>사용자 상세 모달

특정 사용자를 클릭하면 상세 정보 모달이 표시됩니다.

**기본 정보:**
```
사용자명: hong_gildong
이메일: hong@example.com
역할: user
가입일: 2025-01-15 14:30:25
계좌 인증: ✅ 완료
```

**지갑 정보:**
<그림>사용자 지갑 목록

각 코인별 지갑 표시:
- 💰 잔액
- 📍 주소
- 🔒 상태 (활성/비활성)
- 📊 원화 환산액

**거래 내역:**
- 최근 거래 20건
- 입금/출금/스왑 전체
- 상태 및 금액

**관리 액션:**
- 🔒 **계정 정지**: 의심스러운 활동 시
- 🔓 **정지 해제**: 정상화
- 🗑️ **계정 삭제**: 영구 삭제 (주의!)
- ✏️ **정보 수정**: 이메일 등 수정

### 3.3 지갑 관리

<그림>지갑 관리 섹션

**지갑별 관리:**
- 💰 **잔액 조정**: 수동 입금/출금
- 🔒 **지갑 동결**: 긴급 정지
- 📍 **주소 변경**: 보안 문제 시
- 🔄 **강제 동기화**: 블록체인 재확인

**벌크 작업:**
- 선택한 여러 사용자에게 일괄 처리
- 대량 입금/출금
- 공지 발송

### 3.4 새 사용자 생성

<그림>사용자 생성 폼

**생성 절차:**
1. "새 사용자" 버튼 클릭
2. 정보 입력:
   - 사용자명
   - 이메일
   - 초기 비밀번호
   - 역할 (user/admin)
3. "생성" 버튼 클릭

**자동 처리:**
- ✅ 모든 코인 지갑 자동 생성
- ✅ 초기 잔액 0으로 설정
- ✅ 이메일 발송 (계정 정보)

## 4. 계좌 인증 관리

<그림>계좌 인증 관리 화면

사용자의 1원 인증 요청을 처리합니다.

### 4.1 인증 요청 목록

<그림>인증 요청 테이블

**표시 정보:**
- 👤 **사용자명**: 요청자
- 🏦 **은행명**: 계좌 은행
- 💳 **계좌번호**: 인증할 계좌
- 📝 **예금주**: 실명
- 📅 **요청일**: 제출 시각
- 🎯 **상태**: 대기중/완료/거절
- ⚡ **액션**: 처리 버튼

**상태별 필터:**
- 🟡 **대기중**: 처리 필요
- 🟢 **완료**: 인증 성공
- 🔴 **거절**: 인증 실패

### 4.2 1원 인증 처리 절차

#### Step 1: 요청 확인
<그림>인증 요청 상세

1. 대기중인 요청 클릭
2. 사용자 정보 확인
3. 계좌 정보 검증

**확인 사항:**
- ✅ 예금주명 = 실명 일치 여부
- ✅ 계좌번호 유효성
- ✅ 은행 코드 확인

#### Step 2: 1원 입금
<그림>1원 입금 화면

**입금 방법:**
1. 인터넷뱅킹 또는 뱅킹 앱 사용
2. 사용자의 계좌로 정확히 **1원** 송금
3. 입금자명에 **인증 코드 포함**
   - 형식: `홍길XXXX` (XXXX는 4자리 랜덤 숫자)

**예시:**
```
받는 계좌: 123-456-789012 (홍길동)
입금액: 1원
입금자명: 홍길1234
```

#### Step 3: 인증 코드 등록
<그림>인증 코드 입력

1. GMS에서 "인증 코드 발송" 버튼 클릭
2. 입금자명에 사용한 **4자리 숫자** 입력
3. 저장

#### Step 4: 사용자 확인 대기
- 사용자가 앱에서 4자리 코드 입력
- 자동으로 인증 완료 처리

#### Step 5: 승인 또는 거절
<그림>승인 거절 버튼

**승인:**
1. "승인" 버튼 클릭
2. 사용자 계정 활성화
3. 모든 기능 사용 가능하도록 설정
4. 자동 알림 발송

**거절:**
1. "거절" 버튼 클릭
2. 거절 사유 입력 (필수)
   - 예: "예금주명 불일치", "계좌 사용 불가"
3. 확인
4. 사용자에게 사유 통보

### 4.3 대량 처리

<그림>대량 인증 처리

**일괄 승인:**
- 여러 요청 체크박스 선택
- "선택 항목 승인" 버튼
- 한 번에 처리

**주의:**
- 반드시 각 요청 개별 확인 필요
- 실명 확인 철저히

### 4.4 인증 내역 조회

<그림>인증 완료 내역

**검색 옵션:**
- 사용자명으로 검색
- 은행별 필터
- 날짜 범위 선택
- 상태별 필터

**통계 정보:**
- 📊 총 요청 수
- ✅ 승인 비율
- ❌ 거절 비율
- ⏱️ 평균 처리 시간

## 5. 입출금 관리

<그림>입출금 관리 화면

사용자의 코인 구매 요청, 입금, 출금을 통합 관리합니다.

### 5.1 화면 구성

<그림>탭 구조

**3개 탭:**
1. **💰 코인 구매 요청**: 계좌이체 구매 승인
2. **📥 입금 내역**: 블록체인 입금 조회
3. **📤 출금 요청**: 출금 승인/거절

### 5.2 코인 구매 요청 관리

<그림>구매 요청 테이블

#### 요청 목록
**표시 정보:**
- 👤 **사용자**: 구매 요청자
- 💰 **코인**: 구매할 코인 종류
- 💵 **금액**: 입금한 KRW
- 📊 **수량**: 지급할 코인 수량
- 💳 **입금자명**: 계좌 이체한 이름
- 📅 **요청일**: 신청 시각
- 🎯 **상태**: 대기중/승인/완료/거절
- ⚡ **액션**: 처리 버튼

#### 구매 요청 처리
<그림>구매 요청 상세

**Step 1: 입금 확인**
1. 요청 클릭하여 상세 정보 확인
2. 관리자 계좌 확인
   - 입금액 일치 여부
   - 입금자명 일치 여부
   - 입금 시각 확인

**입금 확인 방법:**
- 🏦 인터넷뱅킹 접속
- 💳 계좌 내역 조회
- 🔍 해당 금액 및 입금자명 검색

**Step 2: 승인 처리**
<그림>승인 버튼

입금 확인 완료 후:
1. "승인" 버튼 클릭
2. 지급할 코인 수량 확인
3. "확인" 버튼

**자동 처리:**
- ✅ 사용자 지갑에 코인 자동 지급
- ✅ 거래 내역 자동 생성
- ✅ 사용자에게 알림 발송

**Step 3: 거절 처리**
<그림>거절 사유 입력

입금 확인 안 됨 또는 문제 발생 시:
1. "거절" 버튼 클릭
2. 거절 사유 입력 (필수)
   - 예: "입금 미확인", "입금자명 불일치", "금액 불일치"
3. "확인" 버튼

**사용자 안내:**
- 거절 사유가 사용자에게 표시됨
- 재요청 가능하도록 안내

#### 검색 및 필터
<그림>검색 및 필터 옵션

- 🔍 **검색**: 사용자명, 입금자명
- 🎚️ **상태 필터**: 대기중/승인/완료/거절
- 💰 **코인 필터**: 전체/BTC/ETH/USDT 등
- 📅 **기간 필터**: 오늘/최근 7일/30일/전체

#### 통계 정보
<그림>구매 통계 카드

```
📊 오늘의 구매
총 요청: 25건
승인: 20건
거절: 2건
대기: 3건
총 금액: ₩15,450,000
```

### 5.3 입금 내역 조회

<그림>입금 내역 테이블

#### 입금 목록
**표시 정보:**
- 👤 **사용자**: 입금한 사용자
- 💰 **코인**: 입금된 코인
- 📊 **수량**: 입금 수량
- 📍 **From 주소**: 발신 주소
- 📍 **To 주소**: 수신 주소 (우리 지갑)
- 🔖 **TxHash**: 트랜잭션 해시
- 📅 **시각**: 입금 시각
- 🎯 **상태**: 대기중/완료/실패
- ✅ **확인 수**: 블록체인 확인 횟수

#### 입금 상세 정보
<그림>입금 상세 모달

특정 입금 클릭 시:
```

사용자: hong_gildong
코인: BTC
수량: 0.05 BTC
원화 환산: ₩3,450,000

From 주소: 1A1zP1eP5QGefi2DMPTfT...
To 주소: bc1qxy2kgdygjrs...

TxHash: 4a5e1e4baab89f3a32518a...
블록 높이: 825,430
확인 수: 6/6 ✅

네트워크 수수료: 0.0001 BTC
상태: ✅ 완료
```

## ❓ 관리자 FAQ

### Q1. 출금 승인 기준은?
**A.** 다음을 확인하세요:
- ✅ 사용자 계좌 인증 완료
- ✅ 충분한 잔액
- ✅ 유효한 출금 주소
- ✅ 보안 이벤트 없음
- ✅ 평소 패턴과 일치

의심스러우면 거절 후 본인 확인하세요.

### Q2. Hot Wallet이 부족하면?
**A.** Cold Wallet에서 충전:
1. Cold Wallet 접속 (오프라인)
2. Hot Wallet 주소로 전송
3. 블록체인 확인 대기
4. GMS에서 잔액 확인

### Q3. 코인 시세가 이상해요
**A.** 다음을 확인:
- API 연동 상태 (코인 관리)
- 외부 거래소 시세 비교
- 수동 시세로 임시 대응

API 장애 시 즉시 수동 모드 전환하세요.

### Q4. 사용자가 입금이 안 된다고 해요
**A.** 순서대로 확인:
1. 입금 내역 테이블에서 TxHash 검색
2. 블록체인 탐색기에서 확인 횟수 체크
3. 6확인(BTC) 또는 12확인(ETH) 완료 확인
4. 네트워크 혼잡도 확인
5. 필요 시 수동 동기화

### Q5. 1원 인증 코드를 잊어버렸어요
**A.** 재발송:
1. 계좌 인증 관리에서 해당 요청 찾기
2. "재발송" 버튼 클릭
3. 새로운 4자리 코드로 1원 재입금
4. 사용자에게 안내

### Q6. 관리자를 추가하고 싶어요
**A.** 새 관리자 생성:
1. 사용자 및 지갑 관리
2. "새 사용자" 버튼
3. 역할을 "admin" 선택
4. 정보 입력 후 생성
5. 초기 비밀번호 안전하게 전달

### Q7. 가스비가 너무 높아요
**A.** 비용 절감 방법:
- ⏰ 네트워크 한가한 시간대 처리
- 🔄 배치 처리 활용
- 🌐 저렴한 네트워크 권장 (BSC, Polygon)
- ⚙️ Gas Price Limit 설정
