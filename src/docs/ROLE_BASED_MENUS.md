## 🎯 권한별 메뉴 구조

### 1. Master (마스터 관리자)
**접근 경로**: `/#master`

**메뉴**:
- 대시보드 (전체 통계)
- 센터 관리
- 에이전시 관리
- 시스템 설정 (Biconomy, 블록체인 네트워크)
- 도메인 관리

**권한**:
- ✅ 모든 센터/에이전시/가맹점/회원 데이터 조회
- ✅ 센터 생성/수정/삭제
- ✅ 에이전시 생성/수정/삭제
- ✅ 도메인 추가/삭제/관리
- ✅ 전역 시스템 설정

---

### 2. Centre Admin (센터 관리자)
**접근 경로**: `admin.example.com`

**메뉴**:
1. **대시보드**: 센터 전체 통계
2. **사용자 & 지갑**: 소속 회원 관리
3. **가맹점 관리**: 소속 가맹점 생성/관리
4. **구매 요청 관리**: 코인 구매 요청 승인/거부 ⭐ **센터만 가능**
5. **스왑 관리**: 스왑 요청 승인/거부
6. **계좌인증 관리**: 회원 계좌 인증 승인/거부
7. **고객센터**: 고객 문의 관리
8. **코인 관리**: 코인 종류 관리
9. **가스비 정책**: 가스비 스폰서 설정
10. **보안 모니터**: 시스템 보안 로그

**권한**:
- ✅ 소속 가맹점 생성/수정
- ✅ 소속 회원 조회/관리
- ✅ 코인 구매 요청 승인/거부 (회원 → 센터)
- ✅ 입출금 관리
- ✅ 스왑 관리
- ✅ 계좌인증 승인/거부
- ✅ 센터 설정 변경 (템플릿, 로고, 색상)
- ❌ 다른 센터 데이터 조회 불가

---

### 3. Agency Admin (에이전시 관리자)
**접근 경로**: `admin.example.com`

**메뉴**:
1. **대시보드**: 에이전시 전체 통계
2. **사용자 & 지갑**: 소속 회원 조회
3. **가맹점 관리**: 소속 가맹점 조회
4. **거래 내역**: 소속 센터/가맹점 거래 조회
5. **스왑 내역**: 스왑 거래 조회
6. **고객센터**: 고객 문의 관리

**권한**:
- ✅ 소속 센터 조회
- ✅ 소속 가맹점 조회
- ✅ 소속 회원 조회
- ✅ 거래 내역 조회 (뷰 전용)
- ❌ 승인/거부 권한 없음
- ❌ 센터/가맹점 생성 불가

---

### 4. Store Admin (가맹점 관리자) ⭐ 제한된 권한
**접근 경로**: `admin.example.com`

**메뉴**:
1. **대시보드**: 가맹점 통계 (커미션, 매출)
2. **소속 회원**: 자기 가맹점 소속 회원만 조회 (뷰 전용)
3. **거래 내역**: 자기 가맹점 소속 회원의 거래만 조회 (뷰 전용)
4. **고객센터**: 고객 문의 관리

**권한**:
- ✅ 자기 가맹점 소속 회원 조회
- ✅ 자기 가맹점으로 유입된 거래 내역 조회
- ✅ 커미션 통계 조회
- ✅ 정산 요청
- ✅ 가맹점 지갑 관리
- ❌ **코인 구매 요청 승인/거부 불가** (센터만 가능)
- ❌ 가맹점 관리 불가 (자기 자신은 가맹점)
- ❌ 회원 직접 생성 불가
- ❌ 계좌인증 관리 불가
- ❌ 코인 관리 불가
- ❌ 가스비 정책 불가
- ❌ 보안 모니터 불가
- ❌ 다른 가맹점 데이터 조회 불가

**핵심**: 
- 가맹점은 **조회 전용(View-Only)** 권한
- 코인 구매 요청은 **회원 → 센터**로 직접 전달됨
- 가맹점은 자기 소속 회원의 통계와 거래 내역만 볼 수 있음

---

## 💰 코인 구매 요청 흐름

### 정상 흐름
```
1. 회원 → 센터에 코인 구매 요청 (deposits 테이블)
2. 센터 관리자가 "구매 요청 관리" 메뉴에서 승인/거부
3. 승인 시 → 회원 지갑에 코인 입금
4. 거부 시 → 회원에게 거부 알림
```

### 가맹점의 역할
```
❌ 가맹점은 코인 구매 요청 승인/거부 불가
✅ 가맹점은 자기 소속 회원의 거래 내역만 조회 가능
✅ 가맹점은 커미션 통계를 보고 정산 요청만 가능
```

## 🔐 권한 체크 로직

### Sidebar.tsx
```typescript
// Role에 따라 메뉴 결정
if (user?.role === 'store') {
  menuItems = storeMenuItems; // 4개 메뉴만
} else if (user?.role === 'agency') {
  menuItems = agencyMenuItems; // 6개 메뉴
} else if (user?.role === 'center' || user?.role === 'admin') {
  menuItems = centerMenuItems; // 10개 메뉴
}
```

### Header.tsx
```typescript
// Role 라벨 표시
{user?.role === 'center' ? '센터 관리자' :
 user?.role === 'agency' ? '에이전시 관리자' :
 user?.role === 'store' ? '가맹점 관리자' : '관리자'}
```
