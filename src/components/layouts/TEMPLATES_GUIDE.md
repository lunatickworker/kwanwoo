# 템플릿 선택 가이드

## 🎯 어떤 템플릿을 선택해야 할까요?

### 🔷 Modern (추천)
**이런 센터에 추천합니다:**
- 현대적이고 세련된 이미지를 원하는 센터
- IT/테크 관련 서비스
- 20-40대 주요 고객층

**주요 특징:**
- 사이드바 네비게이션으로 공간 효율적
- Blue/Purple 컬러로 신뢰감과 현대성
- 둥근 카드로 부드러운 느낌

**적합한 업종:**
- 핀테크
- 암호화폐 거래소
- IT 서비스

---

### 📋 Classic
**이런 센터에 추천합니다:**
- 보수적이고 안정적인 이미지를 원하는 센터
- 금융/법률 관련 서비스
- 40대 이상 주요 고객층

**주요 특징:**
- 상단 네비게이션으로 전통적인 구조
- Gray/White 컬러로 안정감
- 테두리로 명확한 구분

**적합한 업종:**
- 전통적인 금융 서비스
- 법률 자문
- 기업 서비스

---

### ⚪ Minimal
**이런 센터에 추천합니다:**
- 깔끔하고 심플한 이미지를 원하는 센터
- 디자인/크리에이티브 관련 서비스
- 밀레니얼/Z세대 고객층

**주요 특징:**
- 중앙 정렬로 콘텐츠 집중
- Black/White로 미니멀한 느낌
- 불필요한 요소 제거

**적합한 업종:**
- 디자인 스튜디오
- 아트 갤러리
- 프리미엄 브랜드

---

### 🎮 Gaming
**이런 센터에 추천합니다:**
- 역동적이고 활기찬 이미지를 원하는 센터
- 게임/엔터테인먼트 관련 서비스
- 10-30대 주요 고객층

**주요 특징:**
- 각진 디자인으로 역동성
- Green/Yellow/Red로 강렬한 느낌
- 그라디언트 액센트

**적합한 업종:**
- 게임 플랫폼
- e스포츠
- 게임 아이템 거래

---

### 👑 Luxury
**이런 센터에 추천합니다:**
- 고급스럽고 프리미엄한 이미지를 원하는 센터
- VIP/프리미엄 서비스
- 고소득 고객층

**주요 특징:**
- 중앙 정렬로 우아한 느낌
- Gold/Brown으로 고급스러움
- 넉넉한 여백과 Shadow 효과

**적합한 업종:**
- VIP 회원 서비스
- 프리미엄 금융 상품
- 럭셔리 브랜드

## 💡 템플릿 커스터마이징 팁

### 1. 브랜드 컬러 적용
```typescript
const customTheme = {
  colors: {
    primary: '#YOUR_BRAND_COLOR',
    accent: '#YOUR_ACCENT_COLOR',
  }
};
```

### 2. 폰트 변경
```typescript
const customTheme = {
  fonts: {
    heading: 'Your Heading Font',
    body: 'Your Body Font',
  }
};
```

### 3. 템플릿 혼합 사용
- Modern의 레이아웃 + Luxury의 컬러
- Classic의 레이아웃 + Gaming의 컬러

- 실시간으로 모든 페이지에 반영

## ❓ FAQ

### Q: 템플릿을 나중에 변경할 수 있나요?
A: 네! 센터 설정 페이지에서 언제든 변경 가능합니다.

### Q: 여러 템플릿을 섞어서 사용할 수 있나요?
A: customTheme를 사용하면 가능합니다. 한 템플릿의 레이아웃에 다른 템플릿의 색상을 적용할 수 있습니다.

### Q: 모바일에서도 같은 템플릿이 적용되나요?
A: 네! 모든 템플릿은 반응형으로 설계되어 모바일에서도 잘 작동합니다.

### Q: 커스텀 템플릿을 만들 수 있나요?
A: 네! 새로운 레이아웃 컴포넌트를 만들어 추가할 수 있습니다.

### Q: 템플릿 변경 시 데이터가 손실되나요?
A: 아니요! 템플릿은 UI만 변경하며, 모든 데이터는 그대로 유지됩니다.
